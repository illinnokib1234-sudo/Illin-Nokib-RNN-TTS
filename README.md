# Illin Nokib - RNN TTS Project

A voice cloning and text-to-speech project using Coqui XTTS-v2 and Google Colab.

## Project Overview

This project demonstrates how a text-to-speech system can generate speech using a reference voice.

The project uses the Coqui XTTS-v2 multilingual text-to-speech model and Google Colab for GPU-accelerated inference.

## Features

- Voice cloning using a reference WAV file
- Text-to-speech generation
- XTTS-v2 multilingual model
- Automatic GPU/CPU detection
- Slide-by-slide audio generation
- Google Colab implementation
- Reusable Python script
